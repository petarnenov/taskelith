# Taskelith

Self-hosted software factory for parallel development and management of multiple software projects.

**Status: bootstrap.** Version 0.1.0 provides a CLI for project information and the bundled architecture plan. The control plane, workers, web UI, and learning system are planned, not implemented.

## Run

Requires Node.js 22 or newer.

```sh
npx taskelith@0.1.0 --help
npx taskelith@0.1.0 --version
npx taskelith@0.1.0 plan
```

Or install the command globally:

```sh
npm install --global taskelith
taskelith --help
```

The CLI makes no network calls and writes no application state. The npm installation itself accesses the package registry.

## Planned architecture

- Node.js and TypeScript application code, with a pure React SPA.
- Hexagonal core, functional modules, adapters, and versioned plugins.
- Self-hosted remote workers and durable messaging.
- Mandatory SDLC for all agent tasks, with replaceable OpenSpec and SpecKit adapters; each project selects its framework, and OpenSpec is the default, also for Taskelith itself.
- First-class principles: Clean Code, SOLID, hexagonal architecture, microkernel, Docker, contract-first OpenAPI (and AsyncAPI for messages), Makefile-driven operation, a mandatory SDLC framework with OpenSpec as the default for developing Taskelith, and code coverage of at least 75% ([ADR 0004](https://github.com/petarnenov/taskelith/blob/main/docs/decisions/0004-first-class-engineering-principles.md)).
- Neo4j-based learning and accumulated project knowledge.
- Established open-source infrastructure; agent harnesses, open or closed, and SCM integrations (GitHub.com first) are removable plugins on a microkernel. No Electron, embedded browser, native mobile app, or original AO Cloud dependency.

Read the [architecture and delivery plan](docs/architecture.md) for scope, risks, and acceptance criteria.

Development follows the [bootstrap governance policy](https://github.com/petarnenov/taskelith/blob/main/docs/governance.md). The [G0 foundation status](https://github.com/petarnenov/taskelith/blob/main/docs/foundation.md) records the foundation work; G0 was closed on 2026-10-24 ([ADR 0007](https://github.com/petarnenov/taskelith/blob/main/docs/decisions/0007-g0-closure.md)), with its open items deferred to later gates.

## Development

Use the exact Node.js version in `.nvmrc` and the npm version pinned in CI. Development targets the `dev` branch; see the [release flow](https://github.com/petarnenov/taskelith/blob/main/docs/releases.md).

```sh
nvm use
npm ci --ignore-scripts
make hooks    # once per clone: run make verify before every push
make verify   # the same checks CI runs
```

Source is TypeScript; published JavaScript is generated by the build. No runtime npm dependencies are required.

Use the exact Node/npm CI pins to check retained [dependency and license evidence](https://github.com/petarnenov/taskelith/blob/main/docs/dependency-inventory.md). Regenerate it with `npm run inventory:dependencies` after reviewed dependency or generator changes.
